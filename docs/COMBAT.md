# Бой в AstralClash (TFT-стиль)

## Обзор

Бой — **полностью симулируется** в памяти движком `CombatEngine`: тик за тиком (20 тиков/сек) обрабатываются атаки, способности, DoT и победа по уничтожению одной из сторон. Визуал (3D модели на доске) не привязан к тикам боя: модели спавнятся при расстановке и деспавнятся при снятии; во время боя **анимации атак не вызываются** из симуляции (при желании их можно подвязать к событиям атаки/способности отдельно).

---

## Урон

- **Физ. урон** (`takeDamage`): уменьшается бронёй по формуле  
  `mitigation = armor / (armor + 100)` → фактический урон = `raw * (1 - mitigation)`.
- **Маг. урон** (`takeMagicDamage`): то же с `magicResist`.
- **Чистый урон** (`takeTrueDamage`): без снижения, только щит частично поглощает.
- **Щит**: сначала снимается из щита, остаток — с HP.
- **Крит**: 5% шанс, множитель ×1.75 (в `CombatEngine.performAttack`).
- Трейты добавляют онхит (Fire: Burn, Ice: Slow, Quantum: MR shred, Physical: каждый N-й удар — бонус true damage и т.д.).

## Анимации атак

- В **симуляции** боя вызываются только числовые расчёты; вызовов ModelEngine (анимации `attack`/`idle` и т.д.) из `CombatEngine` **нет**.
- Модели юнитов спавнятся при установке на клетку и деспавнятся при снятии/продаже; во время раунда они просто стоят на доске.
- Чтобы «оживить» бой, можно извне (по результатам симуляции или по событиям) вызывать `ModelEngineService.playAnimation(ci, "attack", false)` и т.п.

## Потеря HP после раунда (проигрыш)

Формула урона по «нексусу» проигравшего (в `CombatEngine.calcDamage` и `config.yml`):

```
урон = base + (кол-во выживших вражеских юнитов) + (сумма звёзд выживших)
```

- `base` задаётся в конфиге: **game.loss-damage-base** (по умолчанию 2).
- Этот урон применяется в `RoundManager.processResult`: `loser.takeDamage(result.getDamageTaken())`.

## PvE тестовый режим

Включи в `config.yml`: **game.pve-test-mode: true**. Тогда можно играть одному: каждый раунд твой отряд сражается с **заготовленной волной** из конфига **pve.waves**.

- **pve.waves.1**, **pve.waves.2**, … — списки ID чемпионов (1★) на раунды 1, 2, 3…  
- Если для раунда волна не задана, берётся последняя описанная.  
- Лобби стартует при **одном** игроке (при PvE минимум игроков считается как 1).

Так можно проверять бой и баланс без ботов и других игроков.
