# Next-Gen UI: как сделать AstralClash ещё красивее

Встроенный UI уже даёт: action bar (раунд, золото, HP, фаза), сайдбар (синергии, порядок ходов, отчёт по урону), BossBar в бою, полноэкранные заголовки и звуки при старте боя/победе/поражении, частицы. Ниже — что можно добавить для уровня «сверх майнкрафта».

---

## 1. Ресурс-пак (кастомные шрифты и иконки)

**Идея:** в ресурс-паке задаётся кастомный шрифт, где один символ = полоска HP/маны или иконка (сердце, монета, меч). В чате/action bar/scoreboard мы выводим эти символы — клиент отображает их как полоски и иконки.

**Как сделать:**
- В `assets/minecraft/font/default.json` (или свой font) добавить `providers` с `type: "bitmap"` и текстурами для каждого «символа».
- Текстуры: PNG в `assets/minecraft/font/` (например, `heart.png`, `coin.png`, `bar_full.png`, `bar_empty.png`).
- В коде плагина использовать соответствующие Unicode-символы (например, из приватной области) в строках для action bar / scoreboard.

**Плюсы:** полоски и иконки выглядят как в современных играх, без лимитов ASCII.  
**Минусы:** игроки должны принять ресурс-пак (сервер может выдать его автоматически).

---

## 2. TAB-плагин (список игроков и header/footer)

**Плагины:** [TAB](https://github.com/NEZNAMY/TAB), [NeoTab](https://github.com/NEZNAMY/NeoTab).

**Что дают:**
- Кастомный **header** и **footer** над и под списком игроков (текст, раунд, таймер, место).
- Разные префиксы/суффиксы ников по командам (например, по числу HP или «в игре / в лобби»).

**Интеграция:** через PlaceholderAPI плейсхолдеры вида `%astralclash_round%`, `%astralclash_phase%`, `%astralclash_hp%` — плагин реализует их и подставляет в конфиг TAB.

---

## 3. Голограммы (DecentHolograms / Holographic Displays)

**Идея:** над доской или в лобби — вертикальный блок текста (раунд, фаза, таймер до боя).

**Плагины:** DecentHolograms, Holographic Displays.  
Мы создаём/обновляем голограмму по API плагина в нужной точке мира. Подходит для зрелищного отображения «Round 3», «Combat in 10s» и т.д.

---

## 4. Уже реализовано в плагине

| Элемент | Описание |
|--------|----------|
| **Title на старт боя** | «Round X» + «⚔ COMBAT ⚔» (вкл/выкл в `ui.title-combat`) |
| **Звуки** | Старт боя, победа, поражение (`ui.sound-combat-start`, `sound-victory`, `sound-defeat`) |
| **BossBar** | Полоска «⚔ COMBAT ⚔ N ⚔» в фазе боя (NOTCHED_10) |
| **Частицы** | CRIT при старте боя у каждого игрока |
| **Action bar** | Раунд, золото, HP, юниты, уровень, фаза |
| **Сайдбар** | Синергии, порядок ходов, отчёт по урону после раунда |
| **Полоски над юнитами** | TextDisplay: HP/мана с числами |

## 5. Тестовый бой

Чтобы один раз «запустить бой» и проверить механику и UI:

1. Зайти на сервер, выполнить `/astral join`.
2. Запустить игру одним из способов:
   - **PvE:** в `config.yml` включить `game.pve-test-mode: true` — лобби стартует при одном игроке.
   - **С ботами:** `/astral addbot 2`, затем `/astraladmin forcestart`.
3. В фазе планирования выставить юнитов на доску (лавка → расставить).
4. Дождаться фазы боя — появится заголовок, звук, BossBar, сайдбар с синергиями и порядком ходов.
5. После раунда — сообщение победа/поражение, звук, сайдбар «Round N — Results» с блоком «Damage dealt».

**Мгновенная проверка без ожидания таймеров:**  
В игре, с хотя бы одним юнитом на доске: `/astraladmin testfight` — один бой против PvE волны 1, без изменения HP. В сайдбаре сразу виден отчёт по урону.

## 6. Плагины, которые хорошо сочетаются с AstralClash

| Плагин | Назначение |
|--------|------------|
| **ModelEngine** | 3D модели чемпионов (уже используется) |
| **PlaceholderAPI** | Плейсхолдеры для TAB, чата, голограмм |
| **TAB / NeoTab** | Красивый список игроков и header/footer |
| **DecentHolograms** | Голограммы над ареной |
| **Resource pack (свой)** | Шрифты и иконки для полосок/статов |

Связка «ресурс-пак + TAB + PlaceholderAPI» даёт максимально «next-gen» вид при сохранении ванильного клиента.
